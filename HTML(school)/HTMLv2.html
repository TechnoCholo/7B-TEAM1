⚡ Hacker-Style Arduino Commands ⚡

Neon quick reference for cyber coders

pinMode()

Sets a pin as input or output.

Example: pinMode(13, OUTPUT);

digitalWrite()

Writes HIGH or LOW to a digital pin.

Example: digitalWrite(13, HIGH);

digitalRead()

Reads the value from a digital pin (HIGH or LOW).

Example: int buttonState = digitalRead(2);

analogRead()

Reads the value from an analog pin (0–1023).

Example: int sensorValue = analogRead(A0);

analogWrite()

Writes an analog value (PWM wave) to a pin.

Example: analogWrite(9, 128);

delay()

Pauses the program for a specified time (milliseconds).

Example: delay(1000);
